# 桌咪 0.2.0

这次更新让小纸条更好用，也给桌面上的小猫一个新名字：桌咪。

- **应用更名与新图标**：原「狸花猫桌面宠物」更名为「桌咪」，使用白底、黑色线条的轻跃小猫图标。
- **历史范围筛选**：选择开始、结束日期，按天分组滚动浏览完整记录，支持今天、近 7 天、近 30 天与全部。
- **直接复制待办**：无需进入编辑，可选中文字按 ⌘C、右键复制全文，或点击复制按钮；已完成记录与历史也支持复制。
- **纸张配色**：提供奶油黄、蜜桃橙、樱花粉、薄荷绿、晴空蓝和浅藤紫，重启后保留选择。
- **更简洁的菜单**：收起大小、音效和动态设置，移除面向开发验收的试喂与动作预览入口。
- **版本与应用内更新**：菜单显示当前版本，可检查新版、查看更新说明并下载安装。支持每天自动检查，在菜单栏提示新版本；安装由你确认。
- **保留已有数据**：待办、便签、猫咪位置、大小与配色设置继续保留。

适用于 Apple Silicon Mac，最低 macOS 13。

从 0.1.x 升级时，需要手动安装这一次：先退出旧应用，再把「桌咪.app」放进“应用程序”。确认运行正常后，可移除旧名称的应用，避免同时启动两只猫。请保留用户数据目录。安装 0.2.0 后，后续版本可从菜单中的「检查更新…」升级。
